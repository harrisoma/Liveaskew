# Acceptance flow

1. Create/sign in to LiveAskew with Google (existing provider), or use email when Google is unavailable.
2. Answer Bee's five Fit / Feel / Fabric interview questions.
3. Take or upload a clear, full-length reference photo. Photo stays on the device for the text guide; requesting a try-on uses the existing separate image service.
4. Build a seven-day guide. The server requires seven distinct named outfit formulas; incomplete/provider-failed results keep the member at the photo step with a retry message. Rate limits do not create sample guides.
5. Review Day 1 through Day 7, each with garments, Fit / Feel / Fabric and palette. Save individual looks. Account sync stores the day labels; a sync failure is reported.
6. Choose See this on me separately for photo-based previews; the initial text guide does not claim those previews already exist.

Desktop uses the available page width, with a wide content area and multi-column guide. Mobile retains its touch layout. There is no simulated phone frame on computers.
