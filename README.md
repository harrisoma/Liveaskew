# LiveAskew

LiveAskew is a TanStack Start application deployed on Vercel with Supabase for data and authentication.

## Local development

1. Copy `.env.example` to `.env` and add the required values.
2. Run `npm install`.
3. Run `npm run dev`.

## Verification

```bash
npm run build
npm test
```

Environment files are intentionally excluded from Git. Configure production values in Vercel Project Settings.
